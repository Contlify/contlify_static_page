# Contlify | AI Content Automation Landing Page

A modern, fully responsive, dark-themed landing page designed for **Contlify**—an AI-powered content automation platform. This page is built to be lightweight, fast, and easily deployable via GitHub Pages.

## ✨ Features

*   **Modern Dark UI:** Tailored specifically to the Contlify brand aesthetic using custom Navy and Teal color palettes.
*   **Fully Responsive:** Optimized for desktop, tablet, and mobile viewing.
*   **Zero Configuration:** Uses Tailwind CSS via CDN—no build steps, bundlers, or `npm install` required.
*   **Iconography:** Integrated with FontAwesome 6 for crisp vector icons.
*   **Mockup UI:** Includes a styled CSS grid representing the Contlify dashboard in action.

## 🛠️ Built With

*   **HTML5**
*   **Tailwind CSS** (via CDN)
*   **FontAwesome** (via CDN)
